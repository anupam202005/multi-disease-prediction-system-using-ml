# Multiple Disease Prediction System using Machine Learning

## Overview
This project is a Machine Learning based Multiple Disease Prediction System that predicts:
- Diabetes
- Heart Disease
- Liver Disease
- Kidney Disease

using patient medical parameters and classification algorithms.

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook
